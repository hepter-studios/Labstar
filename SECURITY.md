# Security Policy

Labstar is under active development. Security reports are welcome.

## Reporting

Please do not post sensitive security details in a public GitHub issue.

Use GitHub private vulnerability reporting / Security Advisories for this repository when available. If that is not available, contact Hepter Studios through an official verified business channel and reference the Labstar repository.

Include the affected component, version or commit, reproduction steps, expected and observed behavior, and the potential impact.

## Organization isolation

Labstar's target model is a public platform with private-by-default organizations. Any issue that allows one organization to access another organization's private data, events, files or permissions is considered a high-priority boundary failure.

## Secrets

Never publish production passwords, service-role keys, OAuth secrets, session tokens, GitHub App private keys, signing keys, production invitation tokens or private customer data.

## Disclosure

Please give maintainers reasonable time to investigate and prepare a fix before public disclosure of a sensitive issue.

## Bug bounty

Labstar does not currently advertise a paid bug-bounty program.

Security milestones are tracked in [`docs/INTERNATIONAL_RELEASE_ROADMAP.md`](docs/INTERNATIONAL_RELEASE_ROADMAP.md) and [`docs/LABSTAR_EVOLUTION_ROADMAP.md`](docs/LABSTAR_EVOLUTION_ROADMAP.md).
