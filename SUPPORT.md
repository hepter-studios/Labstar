# 🛰️ Labstar Support

Labstar is under active development and does not yet publish a commercial support SLA.

## Bugs

For reproducible non-sensitive bugs, open a GitHub issue with:

- affected version or commit;
- web or desktop environment;
- reproduction steps;
- expected and observed behavior;
- screenshots/log excerpts only after removing private organization data and credentials.

## Feature ideas

Feature proposals are welcome, especially when they explain the workflow problem rather than only the requested UI.

Check [`docs/LABSTAR_EVOLUTION_ROADMAP.md`](docs/LABSTAR_EVOLUTION_ROADMAP.md) and [`docs/PRODUCT_COMPLETION_MAP.md`](docs/PRODUCT_COMPLETION_MAP.md) first to see whether the capability is already planned.

## Security

Do not use a public issue for sensitive vulnerabilities. Follow [`SECURITY.md`](SECURITY.md).

## Private organization data

Never attach private messages, tokens, repository information, production credentials or customer/company data to a public support issue.

Commercial support channels and SLAs will be defined before broad paid release.
